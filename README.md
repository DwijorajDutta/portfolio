## 🚀 How to Host on GitHub Pages
1. Create a new repository on GitHub named `dwijoraj-portfolio` or `dwijorajdutta.github.io`.
2. Upload `index.html` and `README.md` to your repository.
3. Go to **Settings > Pages**.
4. Set the Source branch to **Main** / `root` (`/`) and click **Save**.
5. Your portfolio site will be live at `https://<your-username>.github.io/dwijoraj-portfolio/`!
